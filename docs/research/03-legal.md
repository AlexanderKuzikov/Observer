Проверено 2026-10-01 живыми HTTP-запросами, DNS-резолвом и GitHub API.

**Границы:** часть описывает внешние системы. О состоянии проектов

**451, а не 403** — `Unavailable For Legal Reasons`. Не бан по IP и не
rate-limit, который можно отсидеть: вендор квалифицирует сам факт запроса
как юридически недопустимый.

**Важная поправка первой версии отчёта:** утверждение «твои парсеры сломаны,
проверь хосты» было неверным. Поиск по коду всех репозиториев показал:
`bkr.sudrf.ru` и `bsr.sudrf.ru` не используются нигде. В судебных проектах —
региональные хосты `*.perm.sudrf.ru` и `*.perm.msudrf.ru`, они отвечают.
`kad.arbitr.ru` встречается только в `docs/*.md` и реестрах `courts.json`.

| Что | Что даёт | Тип | Цена | Статус |

| ЕГРЮЛ/ЕГРИП, файловая интеграция | Полные ежедневные файлы, XML | Выгрузка по атрибутам доступа | Бесплатно, нужны атрибуты | Форматы **4.08/4.07 с 01.02.2026** ✅ |
| **«Мой ОКВЭД» API** | Подбор кодов, пакетные решения | **Открытый API, OpenAPI** | **БЕСПЛАТНО, без аутентификации** | Публичный API 24.03.2026 ✅ |
| ФИАС/ГАР, СПАС v2.0 | Адреса, иерархия | REST | **Требует токен** | 403 «Не указан токен» ✅ |
| ФИАС/ГАР, открытые данные | Полный архив ГАР, XML | ZIP | Бесплатно | Свежайший `data-22092026`, **57,6 ГБ** ✅ |

**«Мой ОКВЭД» — живой и бесплатный:**

- Спека: `service.nalog.ru/okved/api/v1/open-api.yaml` (27 КБ) ✅
- `POST /tree` → **HTTP 200**, возвращает дерево с `main:true` на основном коде ✅
- `POST /search` → **HTTP 500** — серверный баг ФНС, не наш запрос ✅
- `POST /related` → **HTTP 404** ✅
- Все методы только POST. GET → 405

**Протокол egrul.nalog.ru** (из JS, версия 1.8.14):

| Шаг | Запрос | Ответ |
|---|---|---|
| 1 | `POST https://egrul.nalog.ru/` (`frmSearch`) | `{captchaRequired, t}` |
| 2 | `GET /search-result/{t}?r={ts}`, поллинг 1 с | `{status, rows}` |
| 3 | `GET /vyp-request/{t}?r={vyp3CaptchaToken}` | запуск выписки |
| 4 | `GET /vyp-status/{t}`, поллинг | `{status: ready\|wait\|error}` |
| 5 | `GET /vyp-download/{t}` | **PDF** |

**Капча ФНС:** числовая картинка, не SmartCaptcha. `GET /static/captcha.bin?a={token}`.
Диалог — iframe `captcha-dialog.html`, общение через `postMessage
{id:'captcha.ready', data:{captcha}}`. Ошибка: «Вы превысили лимит запросов,
направляемых в единицу времени. Подтвердите, что Вы не робот.»

**Как работает защита на хостах:**

- `sudrf.ru` — главная отдаётся без капчи, старый PHP/jQuery 1.10.1.
- `kad.arbitr.ru` — **DDoS-Guard** (`Server: ddos-guard`, куки `__ddg1_/8_/9_/10_`).
  Капча `pravocaptcha` появляется **после превышения числа попыток**, блокировка
  ~3 минуты. То есть это rate-limit, а не капча на каждый запрос.
- ФНС — числовая картинка, порог по числу запросов.

## 7. Юридические границы

### 152-ФЗ

Реквизиты ЮЛ/ИП персональными данными **не являются**. ФИО физлица — являются.
Если обогащать выписку адресами физлиц или публиковать связку «ИНН ЮЛ → ФИО
физлица» — становишься оператором ПДн со всеми обязанностями, включая
локализацию в РФ.

### Реальные зоны ответственности

| Риск | Оценка |
|---|---|
| Обход CAPTCHA автоматически | средний-высокий: ст. 272 УК РФ, ст. 14.1 КоАП. ФНС и ФССП прямо позиционируют капчу как «подтвердите, что вы не робот» |
| Нагрузка в эффекте DDoS | высокий. 451 — сигнал, что вендор считает нагрузку злоупотреблением. 1 запрос в 3 с и 50 rps — разница между нормой и преступлением |
| Публичная перепродажа выгрузки | высокий |

Информация на сайтах госорганов публична по 149-ФЗ.

### Официальные каналы

| Канал | Условие |
|---|---|
| ФНС Open Data | Бесплатно, без ключа |
| ФНС «Мой ОКВЭД» API | Бесплатно, без аутентификации |
| `ftp.egrul.nalog.ru` | Бесплатно, нужны атрибуты доступа |
| ЕФРСБ REST API | Бесплатно по заявке |
| АИС «Закупки» | Регистрация в ЕИС |

**Неприятная правда про ФИАС API:** бесплатный и официальный, но требует заявки
и токена, а Swagger на странице ФНС сейчас ведёт в никуда. Для ФИАС проще
взять 57-гигабайтный ZIP из Open Data.
