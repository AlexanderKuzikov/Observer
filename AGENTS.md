# AGENTS.md — Observer

Репозиторий исследовательский: **кода нет**, только документация и результаты
аудита. Любая будущая реализация — отдельный проект в `D:\GitHub\`.

## Что это

Сводка проверенных данных об инструментарии и внешних API на 2026 год.
Хранится здесь, потому чтоFindings时效 (срок годности) — 3–6 месяцев:
состояние госреестров и антибот-защиты меняется быстрее, чем меняется код.

## Правила работы для агента

### 1. Не переписывай отчёт молча

Отчёт — срезанный срез на 2026-10-01. Любая правка факта требует:
- указать новую дату проверки;
- сохранить старую формулировку в разделе «История изменений» части;
- не смешивать «проверено» и «выведено» — это разные статусы.

### 2. Статусы достоверности

| Статус | Значение |
|---|---|
| ✅ проверено | Живой HTTP-запрос или чтение первоисточника сегодня |
| ⚠️ частично | Первоисточник прочитан, но есть расхождения в источниках |
| ❓ не верифицировано | Не удалось проверить, домен не отдал контент |

Всегда указывать дату и, где возможно, конкретный HTTP-код.

### 3. Нумерация частей стабильна

`01`…`06` — не переставлять, не объединять без явной команды. Ссылки на
конкретные находки в обсуждении — по имени файла, без номеров строк.

### 4. Проекты пользователя не трогать

Файлы других проектов в `D:\GitHub\` не читать без явного разрешения.
Исключение — `knowledge/`, если задача прямо касается базы знаний.

### 5. Коммиты

- Прямо в `main`, без веток и PR.
- Сообщение по-русски или по-английски, до 72 символов в заголовке, повелительное наклонение.
- Перед коммитом — `git status` и `git diff --stat`.

## Чего в этом репозитории не делать

- Не добавлять код без отдельного решения (ADR в `DECISIONS.md`).
